# Brand tools

Two small pages for the team. Each is a single self-contained file: nothing is uploaded,
stored or sent anywhere; everything happens in the browser.

| Page | What it does |
|---|---|
| `index.html` | **Picture generator.** Monogram profile pictures in the company colours, exported as a 1024 x 1024 PNG for Google Workspace or Slack. |
| `signature.html` | **Email signature builder.** Fill in a person's details, press Copy, paste into Gmail's signature box. White or black version. |
| `kyoto-logo.png` | The logo the copied signatures load. Keep this file at this address: signatures already in use point at it. |

Hosted with GitHub Pages from the `main` branch.

The fonts embedded in the pages (Fredoka, Nunito, Carlito) are open-licence (SIL Open Font License).
